# 本地调试与 GitHub 订阅

仓库中的完整配置和模块始终使用 GitHub 远程下载地址。本地服务只在返回文件时生成本地地址，磁盘文件不会因启动服务、下载或电脑换 IP 而改变，上传前无需替换地址。

## 远程使用

完整配置订阅：[config.yaml](https://raw.githubusercontent.com/s20210117/vpn-config/main/subscription/config.yaml)。

配置中的两份广告规则从 GitHub Raw 下载，使用已有的 `GitHub` 策略组。去广告模块和诊断模块中的 `script-path` 也从 GitHub Raw 下载 JS。文件修改并推送到仓库后，再在手机更新相应配置、规则集或模块。

## 本地使用

Mac 与手机连接同一局域网。启动完整配置订阅并显示当前入口：

```sh
python3 project.py subscription start
python3 project.py subscription status
```

状态输出包含当前网卡 IP 的订阅链接，以及 Mac 的 `电脑名.local` 链接。手机支持局域网名称解析时，优先使用后者，避免 IP 变化后修改入口。

模块下载服务：

```sh
python3 module/serve.py
```

启动输出显示当前 IP 的模块目录地址。按应用目录添加模块，如 `/zhihu/zhihu-adblock.sgmodule`。

| 本地下载内容 | 自动生成的地址 |
| --- | --- |
| 完整配置的两份广告规则 | 当前连接 IP、订阅服务实际端口和规则文件名，下载策略设为 `DIRECT` |
| 模块的 JS | 当前连接 IP、模块服务实际端口和脚本路径 |
| 诊断模块的 `collector` 参数 | 当前连接 IP，以及爱奇艺 18766、知乎 18767、虎牙 18768、Reddit 18769 对应的 `/capture` |

服务使用 TCP 连接实际到达的本机地址生成 URL，不读取客户端填写的 Host，也不会把其他仓库或第三方资源地址改成本地地址。换 IP 后从当前入口重新更新配置和模块即可；手机保存的旧数字 IP 入口本身不会自动迁移。

修改文件后重新下载即可看到新内容，无需重启服务。修改服务程序本身后需要重启。

## 抓广告诊断

在电脑启动对应应用的接收器，例如：

```sh
python3 -B -u module/zhihu/capture_server.py
```

从本地模块服务导入诊断模块时，`collector` 默认值自动填写为当前电脑的接收地址；从 GitHub 导入时，在模块参数中设置自己的完整 HTTP/HTTPS 接收地址。默认值 `off` 不发送记录，响应保持原样。

GitHub Pages、Raw 和 CDN 只提供文件下载，不能充当 POST 抓包接收器。诊断记录保存在对应应用的 `captures/` 目录。

## 完整配置更新

在 Clash-Client 的配置中心添加订阅链接，使用该文件的原始配置，并在配置详情打开随链接更新。修改后点击立即同步；如隧道仍使用旧修订，再重新应用配置。

完整配置、规则集和模块各有自己的更新入口：更新完整配置不保证同时刷新缓存中的规则集或 JS。先更新广告 MRS，再更新知乎和虎牙模块。

`subscription/config.yaml` 是当前完整配置；`subscription/original.yaml` 和 `before-*.yaml` 是历史回退快照。历史备份和验证记录中的旧 IP 不参与当前地址生成。

## 服务管理与检查

```sh
python3 project.py subscription start
python3 project.py subscription status
python3 project.py subscription stop
```

Mac 也可以双击根目录的启动、停止和查看订阅地址脚本。订阅后台管理使用 macOS 进程查询和信号；其他系统使用 `python3 project.py subscription serve` 前台运行。本地响应的动态地址生成不依赖 macOS。

订阅服务监听端口 8765，仅接受本机和私有 IPv4 来源，并只提供：

| 路径 | 用途 |
| --- | --- |
| `/config.yaml` | 按当前连接地址生成的完整配置 |
| `/ads-merged.mrs` | 域名广告规则，二进制内容保持原样 |
| `/ads-merged-extra.yaml` | 广告补充规则 |
| `/health` | 服务状态及下载元数据 |

服务状态中的大小、SHA-256 和 ETag 对应实际返回内容；本地完整配置的 URL 经过转换，哈希可能与仓库文件不同。服务不记录配置正文、请求头或凭据。状态文件位于 `~/Library/Application Support/vpn-config/`，日志位于 `~/Library/Logs/vpn-config/`。

Mac 睡眠、关机或服务停止时无法从本地入口更新，已缓存文件仍可使用；GitHub 入口使用远程文件。

```sh
python3 -B -m unittest discover -s tests
python3 project.py check
```

测试使用隔离的本机临时服务，检查动态 IP、端口、下载策略、编码、HEAD 长度、源文件不变和抓包接收参数，不连接手机。
