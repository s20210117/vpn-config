# 迁移依赖与换电脑说明

更新日期：2026-11-27。

## 地址模式

仓库保存 GitHub 远程地址，本地服务按每次下载连接的实际 IP 和端口生成本地地址。换电脑或换网段无需修改源文件中的规则下载 URL、模块脚本 URL 或诊断接收 IP。

| 内容 | GitHub 下载 | 本地服务下载 |
| --- | --- | --- |
| 完整配置中的广告规则 | GitHub Raw，通过 `GitHub` 策略组下载 | 当前电脑 IP 和订阅服务端口，通过 `DIRECT` 下载 |
| 模块 JS | GitHub Raw | 当前电脑 IP 和模块服务端口 |
| 诊断接收地址 | 在模块 `collector` 参数中设置，默认 `off` | 自动填写当前电脑 IP 和对应接收器端口 |

GitHub 文件发布后即可用于远程下载，不需要运行上传前替换脚本或 Git 钩子。历史备份中的地址保留其原始记录。

## 换电脑

1. 在旧位置停止正在运行的订阅服务，再复制项目。
2. 安装 Python 3.9+，执行文件检查。
3. 在新位置启动订阅和模块服务。
4. 手机若使用旧电脑的数字 IP 或电脑名入口，更新为新服务显示的地址；使用 GitHub 入口无需更换链接。

```sh
python3 project.py subscription stop
python3 project.py check
python3 project.py subscription start
python3 project.py subscription status
python3 module/serve.py
```

Mac 的状态输出同时提供 `电脑名.local` 入口；同一电脑换 IP 时，支持局域网名称解析的手机可继续使用该名称。跨网段或不支持名称解析时，使用当前 IP。服务无法替手机更改已经保存的旧订阅入口。

仓库复制不会复制操作系统的网卡配置，也不会修改新电脑的 IP、DNS 或路由器设置。

## 运行环境

| 项目 | 当前实现 |
| --- | --- |
| 文件检查、构建辅助、本地 HTTP 服务 | Python 3.9+，标准库 |
| 完整配置订阅端口 | 8765 |
| 模块下载端口 | 默认 18765，可用 `--port` 指定 |
| 抓包接收端口 | 爱奇艺 18766、知乎 18767、虎牙 18768 |
| 当前 IP 自动显示 | Mac 枚举网络接口；其他系统可自行查看 IP |
| 本地响应地址生成 | 使用 TCP 连接实际到达的本机地址，适用于支持的 Python 系统 |
| 订阅后台管理 | macOS，使用用户状态目录和进程查询 |
| 广告 MRS 重建与内核验证 | 另行提供 Mihomo 可执行文件 |

其他系统可前台运行：

```sh
python3 project.py subscription serve
python3 module/serve.py
```

本地服务需要手机与电脑网络可互通，并允许对应 TCP 端口。已有端口被其他程序占用时，先核对占用进程，服务不会自动接管其他程序。

## 验证

打开本机 `http://127.0.0.1:8765/health` 检查订阅服务状态，然后从手机访问当前电脑地址。模块通过本地入口下载时，其 JS 地址应使用下载连接实际到达的电脑 IP；源文件仍应保持 GitHub Raw 地址。

```sh
python3 -B -m unittest discover -s tests
python3 project.py check
```

换手机时，`phone-tests/test_phone_rules.py` 中的手机控制器地址、证书指纹和规则集名称仍需单独核对。这些参数仅用于手机调试，与配置下载服务的动态地址机制无关。
