# 规则输入快照

本目录保存 7 个上游项目的 8 份规则输入，以及本地域名补充和误报排除清单，用于重新生成最终广告规则。

- 各项目的 GitHub 仓库、下载地址和文件对应关系见[客户端与广告规则来源](../docs/客户端与广告规则来源.md)。
- 文件条数、SHA-256 和已记录的来源见 [manifest.json](manifest.json)。
- `false-positive-exclusions.txt` 只记录经实际功能日志确认的误报后缀；构建时从广告 MRS 中移除，不需要客户端额外添加 `DIRECT` 规则。
- `local-domains.txt` 保存从知乎和虎牙模块迁移的 12 条域名规则。裸域名只精确匹配，`+.` 表示包含域名本身及子域；构建时与上游去重，不扩大原有匹配范围。爱奇艺仅按接口和响应处理，无域名规则迁入。

HaGeZi、StevenBlack 和 AdGuard 输入经过本地转换；其他四套为保存的 MRS 快照。重建使用本目录现有文件，不会自动下载上游更新。
